# Drosophila mushroom body inputs

`embedded_right.csv` contains a six-dimensional adjacency spectral embedding
for 213 mushroom body neurons. `classes.csv` contains the four reference cell
types used to calculate ARI.

The data are associated with:

Priebe et al. (2017), *Semiparametric spectral modeling of the Drosophila
connectome*, arXiv:1705.03297.

https://arxiv.org/abs/1705.03297
